# Pragati - Design System & UI Specification
*Minimalist Glassmorphism Light Theme • Frosted Glass Surfaces • Lucide Icons • Academic Focus*

---

## 1. Aesthetic Foundations

Pragati features a **modern, minimalist glassmorphism aesthetic** on a pure white / crisp paper canvas.
It avoids dark neon glow and eliminates all informal emojis, delivering an editorial, high-precision educational environment.

### Core Visual Principles
1. **Frosted Glassmorphism**:
   - Translucent white panels with high backdrop blur (`bg-white/80 backdrop-blur-md border border-slate-200/80 shadow-sm`).
   - Cards feel layered, light, and elevated above the subtle paper canvas (`#F8FAFC`).
2. **Strict Iconography (Lucide Only)**:
   - Every action, category, and status indicator uses clean vector icons from `lucide-react`.
   - **STRICTLY NO EMOJIS** in titles, buttons, prompts, badges, or empty states.
3. **Restrained Color Palette**:
   - Canvas: `#F8FAFC` (Off-white paper)
   - Glass Card Surfaces: `rgba(255, 255, 255, 0.85)`
   - Primary Accent (Interactive & Focus): `#0284C7` (Sky-600) / `#0EA5E9` (Sky-500)
   - Secondary Accent (Mastery & AI Intelligence): `#7C3AED` (Violet-600) / `#8B5CF6` (Violet-500)
   - Borders: `rgba(226, 232, 240, 0.8)` (Slate-200) or crisp `border-slate-900` for active focal points.
   - Text Primary: `#0F172A` (Slate-900)
   - Text Muted: `#64748B` (Slate-500)
4. **Academic Precision**:
   - Math formulas rendered cleanly using KaTeX.
   - Dual timers and telemetry rendered in clean monospace typography (`JetBrains Mono`).

### C. Consistent Sidebar (3 Navigation Items)
- Fixed vertical bar: `w-64 bg-white/75 backdrop-blur-md border-r border-slate-200/80`.
- Profile header with user avatar / initials and sign-out button.
- 3 Clear Items:
  1. `Bot` icon: **AI Instructor** (`/instructor`)
  2. `HelpCircle` / `CheckSquare` icon: **Quizzes** (`/quizzes`)
  3. `BarChart3` icon: **Analytics** (`/analytics`)
- Active state: Frosted pill (`bg-sky-50/80 text-sky-700 font-semibold border border-sky-200/60`).

## 3. Screen Specifications

1. **Authentication Screen (`/login`)**:
   - Clean centered frosted glass modal over subtle mesh background.
   - Logo: "Pragati" with `GraduationCap` Lucide icon.
   - Method 1: Google OAuth button with Google icon.
   - Method 2: "Sign in with Email" field with "Send Magic Link" button.
   - Clear feedback toast upon link transmission.

2. **AI Instructor View (`/instructor`)**:
   - Chat feed with translucent messages.
   - Agent messages feature Socratic breakdowns, step-by-step reasoning, and tool action badges (e.g. `Generated Quiz: Calculus Fundamentals`).
   - Action buttons inside chat: "Attempt Generated Quiz", "Review Missed Questions".

3. **Quizzes Arena (`/quizzes`)**:
   - Catalog of available topic quizzes generated by the AI agent.
   - Active Quiz view:
     - Top bar: Live countdown timer (`Clock` icon) and current question dwell timer (`Hourglass` icon).
     - Question prompt with KaTeX math rendering.
     - Option selectors with clean selection states.
     - "Request Hint" button (`Lightbulb` icon) logging hint telemetry.
     - "Skip Question" and "Submit Answer" actions.

4. **Analytics View (`/analytics`)**:
   - Performance scorecard: Overall score, average question dwell time, hint reliance percentage.
   - Test attempt history list with individual breakdown buttons.
   - "Missed & Skipped Questions" panel with "Ask AI Instructor to Explain" action.
